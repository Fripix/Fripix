# Hi, I'm Fripix 👋

I'm passionate about IT and technology, and probably even more about figuring out how things work.
A situation I run into quite often is:

> “I'd like to do this, but in this particular way...”
>
> Then I realize the solution either doesn't exist, doesn't quite fit, or requires far too much tinkering.
>
> So I start looking for another way.

And when I finally find or build something useful, I usually think it might be worth sharing too.

> **If the solution I need doesn't exist, I'll try to build it — the limit is usually imagination.**

## Projects

### FriRSS

[FriRSS](https://github.com/Fripix/Frirss) is a self-hosted, customizable web frontend for FreshRSS.

It started because I wanted a different way to read and organize my feeds, without replacing the solid FreshRSS backend.

It has since grown into a desktop and mobile reader with offline support, grid view, inline video playback, extensive customization, SSO, multi-user support and quite a few other things that weren't originally planned.

And there will probably be other projects here in the future — including some I don't know about yet. :)

## Philosophy

I don't really see mistakes as failures. They're experience — and usually the fastest way to understand what can be done better next time.
If something I need doesn't exist, my first reaction is often to wonder whether I can create it.
I also like looking at problems from a different angle instead of automatically doing things the usual way.
**Think outside the box. The limit is your imagination.**
